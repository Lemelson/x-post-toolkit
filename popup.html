How Video Toolkit works

01Downloads the real media file

On X and Google Drive, the extension resolves the best available video source and hands it to Chrome Downloads.

02Transcribes on your Mac

The native host runs NVIDIA Parakeet locally, verifies the result, then returns clean text to the extension.

03Keeps a small local library

Recent transcripts stay in browser storage for the retention period you choose. Clear them at any time.
